## 幾個我刻意做的取捨

**Tech résumé 裡我沒有放 React 教學。** 它很強，但現在 `LinYao + HAIX + SITCON + BambooFox + emfont` 已經形成非常完整的 engineering narrative。如果投的是 developer advocate、education technology 或 university IT 類職位，再把 BambooFox 或 HAIX 的一部分換成 teaching。

**Research CV 裡我保留 Food Explorer，但沒有把它放 Research Experience。** 這是刻意的。它可以證明你對 human behavior、perceived personalization、large-scale interaction 有非常有趣的實作經驗，但在沒有正式研究倫理／study protocol 的情況下，不應該把它包裝成正式 human-subject research。

**Debate résumé 裡我保留 OmniObserve 和 React 課程，但完全不寫 emfont、Kubernetes、MinIO。** 教授研究與正式大學授課會讓人看到你的 analytical maturity；infra 技術細節則只會稀釋 debate profile。
